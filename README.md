# Adithya AI Engineer Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript. The design uses a premium dark interface with an AI-inspired hero illustration, project cards, skills, education, learning credentials, and contact links.

## Files

- `index.html` — page structure and project content
- `style.css` — visual design, responsive layouts, and CSS illustrations
- `script.js` — mobile navigation and active-section highlighting

## Run locally

Open `index.html` in a modern browser. Alternatively, run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with Vercel

1. Upload the files in this folder to the root of a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that GitHub repository.
3. Select **Other** as the framework preset if prompted.
4. No build command is required for this static HTML site. Deploy it.
